# PersonFu HackRF Spectrum Lab Roadmap

This repo should become a high-quality RF education library for owned lab gear, synthetic captures, public documentation, and defensive signal literacy.

## FLLC content split

| Tier | Share | Content |
|---|---:|---|
| Free | 50% | RF basics, antenna notes, lawful monitoring ethics, synthetic waterfall screenshots |
| Basic | 15% | Lab worksheets, report templates, equipment checklists, field log examples |
| Premium | 35% | Interactive WebGL FFT simulator, guided signal classification labs, member-only visual workbenches |

## Priority lab lanes

- HackRF setup and calibration checklist.
- Receive-only ethics and local compliance notes.
- Synthetic I/Q sample catalog for browser visualizers.
- Waterfall interpretation: burst, carrier, sweep, hopping-like patterns using generated samples.
- Antenna and connector matching: SMA/MCX/N-type puzzle cards.
- RF report writing: frequency, bandwidth, modulation guess, equipment, environment, limitations.

## Boundary

No jamming, spoofing, deauthentication, unauthorized interception, bypassing encryption, or operational tracking. Keep public artifacts educational, synthetic, receive-only, and owned-lab scoped.
